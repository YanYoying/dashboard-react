# FinAnalytics

Dashboard frontend para visualização de indicadores e dados fictícios do mercado financeiro. Inclui KPIs, tabela de ativos e gráficos de desempenho e volume.

## Tecnologias

React, Vite, Recharts, Lucide React e CSS.

## Executar

```bash
npm install
npm run dev
```

Use `npm run build` para gerar o frontend estático. Os dados são demonstrativos e não devem orientar decisões financeiras.
